Minefield Protocol is a board game prototype created for VGC 107 – History of Video Games.

The game combines private action programming, public resolution, and a hidden minefield. Players plan ahead while navigating uncertain information and competing to survive.

The browser prototype

Built with plain HTML, CSS, and JavaScript, the prototype supports local pass-and-play and solo matches with local bots. It runs offline without installation.
